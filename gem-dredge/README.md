project. Implements the Gemini web RPC surface (batchexecute) with CDP-based
session auth against a live Chromium instance.

Goal: find deleted conversations the backend still serves — names in the
sidebar (MaZiqc) minus backend-retained rows (hNvQHb), or vice versa.
